Connect Patreon

Register a v2 client at patreon.com/portal → Clients & API Keys, then paste the Creator's Access Token. Client ID/secret + refresh token are optional — without them an expired token just needs re-pasting.

Auto-refresh credentials (optional)

Register a v2 client at patreon.com/portal → Clients & API Keys with redirect URI http://127.0.0.1:53124/callback, then sign in with your Patreon account to see your memberships.
